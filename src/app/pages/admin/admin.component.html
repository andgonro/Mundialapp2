Cómo publicar los cambios

  1. Usa el editor de arriba para actualizar partidos y goleadores.
  2. Opción GitHub: introduce la clave y pulsa "Publicar en GitHub" (crea commit automático).
  3. Opción Blobs: pulsa "Publicar en Blobs" con la misma clave; activa blobsBackend: true en environment.prod.ts para que la web lo use.
  4. Si no tienes clave, descarga data.json y súbelo manualmente al repo.
  5. Recarga la web para ver la clasificación recalculada al instante.
