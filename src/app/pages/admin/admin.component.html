Cómo publicar los cambios

  1. Selecciona partido, actualiza marcador y registra goleadores en el mismo bloque.
  2. Si el cruce acaba en penaltis, marca la casilla y elige ganador para el avance.
  3. Pulsa "Aplicar cambios del partido" para guardar resultado y estado finalizado.
  4. Introduce la clave y pulsa "Publicar Actualización" para guardar los datos en Blobs.
  5. Recarga la web para ver la clasificación recalculada al instante.
